B7 FI Command Center v0.49.0 — Knowledge Base + Framework Fix

Built directly from v0.48.0.

- FI Knowledge Base is now a fully editable/searchable page.

- Search covers all stored reference fields.

- Bottom Fleet Status reads the live computed page accent after every render instead of relying on stale hard-coded orange.
- Shared Data inactive navigation styling no longer carries the persistent blue box.
- Critical browser cache fix: styles-v0300.css query updated from v0470 to v0490 so the newest CSS actually loads on GitHub Pages.
- Existing v0.48.0 Morning Meeting Notebook, Weekend workflow, lifecycle cards, Tool Detail,
  Customer Requirements, Action Center, Wallboard, Shared Data and Reference Files are preserved.
