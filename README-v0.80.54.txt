B7 FI Command Center v0.80.54 — Centralized Page Navigation Framework

This build replaces the v0.80.53 delayed toolbar recovery layer with one final page-navigation controller.

Conventions:
- LEFT = pages/destinations within the active Center.
- RIGHT = actions for the active page.
- Edit modes replace normal actions with SAVE / CANCEL.

Defined Centers:
- Tool: CYxxQx Tools | Tool Countdown | Tool Archive; contextual Add/Edit/Archive/Save/Cancel/Delete.
- Priority: Weekday Priorities | Weekend Priorities; contextual Edit/Save/Cancel.
- Shipping: no left navigation; Edit Ship Schedule selector, Screenshot, Report.
- Status: Weekday Morning Status | Leads Extra Status | Weekend Morning Status; contextual Edit/Save/Cancel.
- Meeting: Morning Status | Leads Meeting | ORB Meeting | FE Options Meeting | Cell Meeting; body emphasizes history; Start/Save/Cancel on right.
- Action: no left navigation; Add Alert / Save / Cancel on right.
- Reference: FI Knowledge | Reference Files; Add Reference Note or Load File actions.
- Search: no left navigation; Screenshot / Report only; search stays in body.

Tool Archive bulk workflow and individual Tool Delete are retained.
