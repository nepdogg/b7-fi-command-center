Tool Center Standard/Mini Tool Card update:
- Keeps the existing full-size photo Tool Card for Operations/Live Status.
- Rebuilds Tool Center live cards as compact photo-less Mini Tool Cards.
- Mini cards reserve fixed positions for FI Testing, Lead/Admin, Micro Schedule, Packing/Shipping, Customer Source, and STR.

- Tool Center defaults to three cards across on desktop for readability.
