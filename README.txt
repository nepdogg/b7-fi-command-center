# Building 7 - Final Integration - Operations v0.8

Simulation-testing update.

## Key changes
- Simplified operational pages and removed redundant headings/taglines.
- Renamed project to Building 7 - Final Integration - Operations.
- Larger Code Name section headings.
- Global lifecycle colors: Waiting for FI red, In FI yellow, Shipped green, Archive gray.
- Cleanroom dropdown CR1 / CR2 / CR3.
- Added Cleanroom Bay.
- Tool Status editable from Tool Admin.
- Added Archive state/page; archived tools are preserved but excluded from active calculations.
- Tools grouped by Code Name.
- Independent checklist statuses: Need to Complete / In Progress / Complete / Skipped / N/A.
- Multiple checklists may be In Progress.
- Green check / yellow active / red X / gray skipped-N/A visual system.
- Lead/Admin workflow uses the same visual status language.
- Regera/Celestiq MST date picker; all other Code Names default MST to N/A.
- Morning Status color coding: status/open NC blue, lamp hours yellow, escalated NC red.
- v0.7 browser data is migrated into v0.8 where possible.
