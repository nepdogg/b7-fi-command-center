B7 FI COMMAND CENTER v0.75.0

Visual shell update based on the approved testing screenshots.

Changes:
- Action Status and Fleet Status remain stacked at the top.
- Both status bars keep identical dimensions and three-zone layout.
- Full status-bar perimeter now uses the current message severity color.
- Added a moving perimeter tracer that travels around the complete status bar.
- Kept thick severity-colored dividers between Beacon / Message / Count.
- Fleet and Action center messages are geometrically centered.
- Restored the global footer and kept it visible at the bottom of the app shell.
- Footer layout: Administration / version / KLA+ / production-sync / B7 FI context.
- Header now extends edge-to-edge instead of stopping at the old 1680px shell limit.
- Large header titles reduced slightly for more even top/side spacing.
- No new MutationObserver or recurring interval was introduced in v0.75.0.
