B7 FI Command Center v0.62.0 — Center Navigation / Page Actions Standardization

This testing build applies the latest UX convention across the operational Centers:
- Center-specific page navigation stays on the LEFT of the sticky page bar.
- Current-page actions stay on the RIGHT.
- Edit screens use CANCEL then SAVE CHANGES on the right.
- Legacy cross-Center controls are removed from Center page bars.
- Reference Center is restricted to FI KNOWLEDGE / REFERENCE FILES and promotes ADD REFERENCE NOTE to the page bar.
- Meeting Center promotes START MEETING NOW to the page bar when available.
- Duplicate bottom editor save/apply controls are hidden when the sticky Save Changes action is present.
- Tool-family separation is cleaned up by removing stray divider lines and using spacing/headings.
- Administration Center is intentionally not redesigned in this pass; it remains reserved for the final cleanup phase.
