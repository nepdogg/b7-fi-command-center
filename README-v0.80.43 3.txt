B7 FI Command Center v0.80.43
Tool Center Mini Card Refinement

Changes:
- Tool Center Mini Tool Cards are narrower/denser and target 4 cards across on large desktop screens.
- Responsive layout steps down to 3, 2, then 1 card as screen width decreases.
- Model and Customer moved from the header into the bottom core-information grid.
- Bottom grid now contains Model, Customer, Sales Order, Ship Date, Driver, and Cleanroom.
- Tool Status badge and left card accent now use the same fleet-status color language:
  Waiting FI = red/pink; In FI = gold; Packing = cyan/blue; Shipped = green.
- Existing six workflow rows remain fixed: FI Testing, Lead/Admin, Micro Schedule, Packing/Shipping, Customer Source, STR.
- Existing plan-change indicators remain intact.
