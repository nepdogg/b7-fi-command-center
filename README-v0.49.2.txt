B7 FI Command Center v0.49.2 — Action Center Manual Reminder Control

Built directly from v0.49.1.

Action Center:
- Manual reminders can now be edited.
- Manual reminders can be assigned to a lead.
- Added missing Information category to the reminder category menu.
- Manual reminder Top Status Bar visibility can be turned on/off.
- Top Status Bar duration options: Until Completed, Today Only, 1 Day, 3 Days, 7 Days, Custom End Date.
- Reminder remains in Action Center after its ticker display expires; it stays open until manually completed.
- Manual reminder cards show assignee and ticker-display information.
- Manual reminders can be marked Complete directly from Action Center.
- Automatic/generated tasks are NOT made editable and keep their existing condition-based behavior.
- Automatic alerts always remain eligible for the top status bar while their underlying condition exists.
- Bottom Action count continues to represent all open Action Center items, not only ticker-visible reminders.

All v0.49.1 header/Page Actions corrections and prior Command Center workflows are preserved.
