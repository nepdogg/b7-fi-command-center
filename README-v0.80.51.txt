B7 FI COMMAND CENTER v0.80.51 — TOOL CENTER FRAMEWORK FINALIZATION

- Tool Countdown helper description removed.
- Tool Archive simplified to the archived-tools table only.
- Added ARCHIVE TOOL action on Tool Archive.
- ARCHIVE TOOL opens a fast active-tool list with FI Status selection.
- Archive mode page actions become CANCEL / SAVE.
- SAVE gives explicit acknowledgement; SAVE with no changes says No changes to save.
- Archived tools retain their master record/history and disappear from active Tool Center / Countdown / Live Status views.
- When every tool is archived, active views are expected to resolve to an empty fleet: zero active KPIs, no active cards/carousel entries, and no tool-derived alerts.
